# SaDiii AI Chatbot ✦

A responsive chatbot interface branded as **SaDiii AI**, built with **HTML, CSS, and JavaScript**.

## Features
- Responsive chat interface
- Suggested prompts
- Simple rule-based demo replies
- New chat button
- Typing indicator
- No installation or API key required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Important note
This is a frontend chatbot demo. Its replies are generated using simple JavaScript rules; it is **not connected to a real AI model**. To enable real AI responses, connect a backend to an AI API. Never put a private API key directly in frontend JavaScript.

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
